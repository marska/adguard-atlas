# AdGuard Atlas

A self-hosted world map of your network's DNS queries, live. It reads the query log
of one or more [AdGuard Home](https://github.com/AdguardTeam/AdGuardHome) instances
and draws an arc from your home to wherever each answer points.

**Status: specification only — nothing to run yet.** See [docs/SPEC.md](docs/SPEC.md).

It shows what devices asked for, not where traffic actually went.

A public demo with generated traffic is planned; the real thing runs locally, next to
your AdGuard Home.
